# Lecture study tools

Choose **Lecture** next to the title, then record or add a lecture. Existing text can be pasted too. Live words arrive in short batches; wait for the final words after stopping. Correct important terms in Transcript before choosing **Create study notes**.

Study notes has three views:

- **Notes**: an editable outline, key concepts, definitions and examples. Quick notes quote selected passages across the whole lecture. Empty categories say that no explicit source was found.
- **Revision**: choose a question, try answering, then select Show answer. You can edit the question and answer. They are saved separately from the written notes.
- **Sources**: original excerpts, timestamps and Go to transcript. A card's Check source opens its excerpt. Selecting a source does not start playback automatically; use Play if desired.

Save a copy exports the selected Notes, Revision or Sources view to Word, PDF, text or Markdown. JSON preserves the entire project and evidence. SRT always exports the transcript. Changes save automatically; Settings provides backup and restore.

Switching between Meeting and Lecture keeps both kinds of documents. Creating fresh notes asks before replacing existing study edits. Transcript corrections keep the old study notes and show a warning until you regenerate them. The stored excerpts still reflect the earlier transcript, so the selected playback/transcript position may need comparison.

## What the study aids can and cannot establish

Quick notes join split caption sentences, then select source passages and use English cues to identify explicit definitions and examples. They preserve numbers, symbols and negations in those excerpts, but recognition can already have misheard them. Categories are heuristic, selected passages are limited, and not every topic becomes a card. Review the full transcript and course materials. A transcript excerpt is not a verified textbook answer.

Polished notes use the separately installed local writing helper. It processes all bounded source chunks, suggests concepts/questions and retains original source answers. Unknown source references and new numeric claims reject the generated result and trigger quick notes. This does not detect every possible hallucination or reversed meaning. AI material is marked as a draft. A missing helper does not block basic lecture notes.

There is no slide/PDF ingestion, handwriting/equation OCR, translation, automatic lecturer identification or exam prediction. Accuracy and learning outcomes have not been benchmarked against real lectures. Acceptance should include an actual lecture in each target subject/language, a check of technical terms and formulas, and target-device recording tests. The sample and automated tests establish software behavior, not lecture comprehension quality.
