# 0.5.0 lecture-mode verification

Status: implementation complete; Windows build and private release preparation pending. No public 0.5.0 release has been published or main merged.

Adds dedicated lecture notes and source-backed revision practice while retaining all 0.4.1 guide/update/footer changes. Schema 5 migrates old libraries with a snapshot and keeps meeting and study documents separate. Newer unknown schemas are rejected instead of downgraded.

Automated cases cover split live captions, long-lecture tail coverage, formulas/negation, literal markup, source hashes, invalid AI sources/numbers, unavailable writing helper fallback, migration, future-schema rejection, mode/save failure guards, editable cards with immutable evidence, changed-transcript warnings, source navigation, guide choices, six exports and both themes at compact laptop sizes.

See LECTURE_MODE.md for usage and limitations. Real lecture accuracy, physical audio, 8 GB target hardware, actual Ollama quality and assistive technology are not certified by synthetic/offscreen tests. This is an unsigned beta pending user acceptance.
